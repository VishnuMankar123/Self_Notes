# 🔥 CRUD OPERATIONS IN ASP.NET WEB API

## 🔹 CRUD ka matlab

| Operation  | HTTP Verb | Kaam                 |
| ---------- | --------- | -------------------- |
| **Create** | POST      | New data insert      |
| **Read**   | GET       | Data fetch           |
| **Update** | PUT       | Existing data update |
| **Delete** | DELETE    | Data remove          |

---

## 🧱 Example Entity (Student)

```csharp
public class Student
{
    public int StudentId { get; set; }
    public string StudentName { get; set; }
    public int Age { get; set; }
}
```

---

## 🧠 DbContext

```csharp
public class SchoolContext : DbContext
{
    public DbSet<Student> Students { get; set; }
}
```

---

## 🎯 API Controller

```csharp
using System.Collections.Generic;
using System.Linq;
using System.Web.Http;

public class StudentsController : ApiController
{
    SchoolContext db = new SchoolContext();
```

---

## 1️⃣ READ – Get All Students (GET)

```csharp
[HttpGet]
public IHttpActionResult GetStudents()
{
    var students = db.Students.ToList();
    return Ok(students);
}
```

📌 URL:

```
GET /api/students
```

---

## 2️⃣ READ – Get Student By ID (GET)

```csharp
[HttpGet]
public IHttpActionResult GetStudent(int id)
{
    var student = db.Students.Find(id);

    if (student == null)
        return NotFound();

    return Ok(student);
}
```

📌 URL:

```
GET /api/students/1
```

---

## 3️⃣ CREATE – Insert Student (POST)

```csharp
[HttpPost]
public IHttpActionResult AddStudent(Student student)
{
    if (!ModelState.IsValid)
        return BadRequest(ModelState);

    db.Students.Add(student);
    db.SaveChanges();

    return Ok("Student Added Successfully");
}
```

📌 URL:

```
POST /api/students
```

📌 JSON Body:

```json
{
  "StudentName": "Rahul",
  "Age": 22
}
```

---

## 4️⃣ UPDATE – Update Student (PUT)

```csharp
[HttpPut]
public IHttpActionResult UpdateStudent(int id, Student student)
{
    if (id != student.StudentId)
        return BadRequest("ID mismatch");

    var existingStudent = db.Students.Find(id);

    if (existingStudent == null)
        return NotFound();

    existingStudent.StudentName = student.StudentName;
    existingStudent.Age = student.Age;

    db.SaveChanges();

    return Ok("Student Updated Successfully");
}
```

📌 URL:

```
PUT /api/students/1
```

📌 JSON Body:

```json
{
  "StudentId": 1,
  "StudentName": "Updated Name",
  "Age": 23
}
```

---

## 5️⃣ DELETE – Delete Student (DELETE)

```csharp
[HttpDelete]
public IHttpActionResult DeleteStudent(int id)
{
    var student = db.Students.Find(id);

    if (student == null)
        return NotFound();

    db.Students.Remove(student);
    db.SaveChanges();

    return Ok("Student Deleted Successfully");
}
```

📌 URL:

```
DELETE /api/students/1
```

* **GET** → Data read
* **POST** → Insert
* **PUT** → Update
* **DELETE** → Remove
* `IHttpActionResult` → Proper HTTP response
* `Ok()` → 200
* `NotFound()` → 404
* `BadRequest()` → 400

# 🔥 IHttpActionResult vs IActionResult

## 📌 Short answer (yaad rakhne ke liye)

> **IHttpActionResult → ASP.NET Web API (old / .NET Framework)**
> **IActionResult → ASP.NET Core (new / modern)**

---

## 1️⃣ **IHttpActionResult kya hai?**

👉 Ye **ASP.NET Web API (System.Web.Http)** ka interface hai
👉 Sirf **Web API (.NET Framework)** me use hota hai

### Example:

```csharp
using System.Web.Http;

public class StudentsController : ApiController
{
    [HttpGet]
    public IHttpActionResult GetStudents()
    {
        return Ok("Hello Web API");
    }
}
```

### Common methods:

* `Ok()` → 200
* `NotFound()` → 404
* `BadRequest()` → 400
* `InternalServerError()`

---

## 2️⃣ **IActionResult kya hai?**

👉 Ye **ASP.NET Core (Microsoft.AspNetCore.Mvc)** ka interface hai
👉 **MVC + Web API dono** me use hota hai
👉 Modern, fast, cross-platform

### Example:

```csharp
using Microsoft.AspNetCore.Mvc;

[ApiController]
[Route("api/[controller]")]
public class StudentsController : ControllerBase
{
    [HttpGet]
    public IActionResult GetStudents()
    {
        return Ok("Hello ASP.NET Core");
    }
}
```

### Common methods:

* `Ok()`
* `NotFound()`
* `BadRequest()`
* `CreatedAtAction()`
* `NoContent()`

---

## ⚔️ Side-by-Side Comparison (INTERVIEW GOLD 🔥)

| Point           | **IHttpActionResult** | **IActionResult**        |
| --------------- | --------------------- | ------------------------ |
| Framework       | ASP.NET Web API       | ASP.NET Core             |
| Namespace       | System.Web.Http       | Microsoft.AspNetCore.Mvc |
| Platform        | Windows only          | Cross-platform           |
| Performance     | Normal                | Faster                   |
| MVC + API       | ❌ Only API            | ✅ Both                   |
| Future support  | ❌ Legacy              | ✅ Actively supported     |
| Controller base | ApiController         | ControllerBase           |

---

## 🧠 Controller inheritance difference

### Old Web API:

```csharp
public class StudentController : ApiController
```

### ASP.NET Core:

```csharp
public class StudentController : ControllerBase
```

---

## 📌 Return type alternatives (important!)

### Web API (old):

```csharp
public IHttpActionResult Get()
```

### ASP.NET Core:

```csharp
public IActionResult Get()
public ActionResult<Student> Get()
```

👉 **ActionResult<T>** is BEST practice in Core

---

## 🔥 Real-world recommendation (Tumhare liye)

Tum:

* ASP.NET Web API seekh rahe ho
* MVC + SQL + API kar rahe ho

### ✔️ Abhi:

👉 `IHttpActionResult` → OK (learning + legacy projects)

### ✔️ Future / New projects:

👉 **ASP.NET Core + IActionResult / ActionResult<T>**

---

## 🧠 One-liner yaad rakhne ka

> **IHttpActionResult = Purana Web API**
> **IActionResult = Naya ASP.NET Core**

---

## ❓ Interview me agar pooche:

**Q: Which one should we use today?**

✔️ Best answer:

> “For new development, ASP.NET Core with IActionResult or ActionResult<T> is recommended. IHttpActionResult is used only in legacy Web API projects.”
