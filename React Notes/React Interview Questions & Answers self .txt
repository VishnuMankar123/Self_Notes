# React Interview Questions & Answers (Part 1)

## 1. React me kitne type ke Components hote hai?

### Answer

React me mainly **2 type ke components** hote hai.

1. Class Component
2. Functional Component

Aaj ke time me mostly **Functional Components + Hooks** use hote hai.

---

## 2. Class Component kya hota hai?

### Answer

Class Component ES6 class se banta hai.

Isme:

* state hoti hai
* lifecycle methods hote hai
* this keyword use hota hai

Pehle React me isi ka use hota tha.

---

## 3. Functional Component kya hota hai?

### Answer

Functional Component ek normal JavaScript function hota hai jo JSX return karta hai.

Hooks aane ke baad ye state aur lifecycle dono support karta hai.

Aaj ke time me isi ko prefer kiya jata hai.

---

## 4. Aaj ke time me kaunsa Component use karna chahiye?

### Answer

Functional Component.

Reason:

* Simple
* Less code
* Easy to read
* Hooks support
* Better performance

---

## 5. Functional Component ka sabse bada advantage kya hai?

### Answer

Hooks use kar sakte hai.

Example:

* useState
* useEffect
* useRef
* useMemo

---

## 6. Class Component me state kaise banate hai?

### Answer

Constructor ke andar.

```jsx
this.state = {
   count:0
}
```

---

## 7. Functional Component me state kaise banate hai?

### Answer

useState Hook se.

```jsx
const [count,setCount]=useState(0);
```

---

# export default

## 8. export default kya hota hai?

### Answer

Ye kisi component ko dusri file me use karne ke liye export karta hai.

Example

```jsx
export default App;
```

---

## 9. import ka use kyu karte hai?

### Answer

Dusri file se component ko lane ke liye.

```jsx
import App from "./App";
```

---

## 10. Kya ek file me multiple default export ho sakte hai?

### Answer

❌ Nahi.

Ek file me sirf **ek default export** ho sakta hai.

---

## 11. import karte waqt naam change kar sakte hai?

### Answer

✅ Haan.

```jsx
import MyApp from "./App";
```

Actual component App hi hai lekin import kisi bhi naam se kar sakte hai.

# State

## 1. State kya hoti hai?

### Answer

State component ki **memory** hoti hai.

Dynamic data state me store hota hai.

State change hote hi component re-render hota hai.

---

## 2. State ko Functional Component me kaise banate hai?

### Answer

`useState()` Hook se.

```jsx
const [count, setCount] = useState(0);
```

---

## 3. useState() kya return karta hai?

### Answer

Ye 2 values return karta hai.

```jsx
const [count, setCount] = useState(0);
```

* `count` → Current Value
* `setCount` → Update Function

---

## 4. State ko direct change kar sakte hai?

### Answer

❌ Nahi.

Wrong

```jsx
count = count + 1;
```

Correct

```jsx
setCount(count + 1);
```

---

## 5. setCount() call karne ke baad kya hota hai?

### Answer

* State update hoti hai.
* Component re-render hota hai.
* React DOM update karta hai.

---

## 6. Class Component me state kaise banate hai?

### Answer

```jsx
this.state = {
   count:0
}
```

Update

```jsx
this.setState({
   count:1
})
```

---

## 7. Functional Component me state kaise update hoti hai?

### Answer

`setState` function se.

Example

```jsx
setCount(count + 1);
```

---

# Props

## 8. Props kya hote hai?

### Answer

Props ka matlab Properties.

Parent Component Child Component ko data bhejta hai.

---

## 9. Props ka flow kis direction me hota hai?

### Answer

Parent

↓

Child

One Way Data Flow.

---

## 10. Kya Child Component props change kar sakta hai?

### Answer

❌ Nahi.

Props Read Only hote hai.

---

## 11. Props aur State me difference?

### Answer

Props

* Parent bhejta hai.
* Read Only.

State

* Component khud manage karta hai.
* Change ho sakti hai.

---

## 12. Props destructuring kya hota hai?

Without

```jsx
props.name
```

With

```jsx
const Greeting = ({name}) => {}
```

### Answer

Props object se values directly nikalna.

Code clean aur readable ban jata hai.

---

# useRef

## 13. useRef kya hai?

### Answer

useRef ek Hook hai.

Ye kisi DOM element ka reference store karta hai.

---

## 14. useRef() kya return karta hai?

### Answer

Object return karta hai.

```javascript
{
   current:null
}
```

---

## 15. inputRef.current kya hota hai?

### Answer

Input DOM element ka address.

---

## 16. inputRef.current.value kya deta hai?

### Answer

Input box ki current value.

---

## 17. useRef kab use karte hai?

### Answer

* Input value lena
* Focus karna
* DOM access karna
* Video play/pause

---

## 18. useRef aur useState me difference?

### Answer

useState

* UI update karta hai.
* Re-render hota hai.

useRef

* Reference store karta hai.
* Re-render nahi hota.

---

# Controlled vs Uncontrolled

## 19. Controlled Component kya hota hai?

Input ki value React State me store hoti hai.

React input ko control karta hai.

---

## 20. Uncontrolled Component kya hota hai?

### Answer

Input ki value DOM me hoti hai.

React `useRef` se value leta hai.

---

## 21. Forms me kaunsa use karna chahiye?

### Answer

Mostly

✅ Controlled Component.

---

## 22. Controlled Component me input value kaha store hoti hai?

### Answer

React State me.

---

## 23. Uncontrolled Component me input value kaha store hoti hai?

### Answer

Browser DOM me.

## 24. DOM kya hai?

Usi ko DOM bolte hai.

---

## 25. JavaScript DOM ko kaise access karti hai?

### Answer

```javascript
document.getElementById()
```

---

## 26. React directly DOM update karta hai?

### Answer

❌ Nahi.

Pehle State update hoti hai.

Fir React DOM update karta hai.

---

## 27. DOM update ka flow batao.

### Answer

```

↓

State Change

↓

Component Re-render

↓

New JSX

↓

Compare

↓

DOM Update
```

## 31. React me `{}` ka use kyu hota hai?

### Answer

JSX ke andar JavaScript likhne ke liye.

---

## 32. `{name}` ka matlab?

Inline CSS ke liye.

Example

```jsx

```

Pehla `{}` → JSX

Dusra `{}` → JavaScript Object

* Function Call

* Ternary Operator
* map()
