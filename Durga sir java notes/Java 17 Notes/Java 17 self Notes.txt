## Q6. Sealed Class kya hoti hai?

# Student 👨‍🎓

Normally Java me koi bhi class kisi class ko extend kar sakti hai.

```java

{
}
```

```java

```



## Q5. Java 17 ne kya improve kiya?

# 👨‍🎓 Student

Java 17 ne **Pattern Matching for Switch** introduce kiya.

Ab switch statement sirf int ya String ke liye nahi.

Object ke different types bhi handle kar sakta hai.

---

## Example

```java
Object obj = "Java";
```

Java automatically check karega

```java
switch(obj)
{
    case String s ->
        System.out.println("String : " + s);

    case Integer i ->
        System.out.println("Integer : " + i);

    case Double d ->
        System.out.println("Double : " + d);

    default ->
        System.out.println("Unknown");
}
```

Ab

✅ No casting

✅ No instanceof

✅ Short code

---


> **"Java 17 me security improvements kya aaye?"**

Aap answer de sakte ho:

* **Strong Encapsulation (JEP 403)** – Internal JDK APIs ko restrict kiya.

Ye teeno points Java 17 ke security-related changes ko cover karte hain aur interview ke liye kaafi strong answer banta hai.

# 🎤 Interview Tip (Very Important)

Agar interviewer pooche:

> **"Java 17 me kya remove hua?"**

Aap confidently bol sakte ho:

* **RMI Activation (JEP 407)** remove hua kyunki modern distributed systems REST APIs, gRPC aur messaging platforms use karte hain.
* **Applet API (JEP 398)** deprecated hui kyunki browsers Java plugins support nahi karte aur HTML5/JavaScript frameworks ne uski jagah le li.
* **Experimental AOT Compiler aur Experimental Graal JIT Integration (JEP 410)** remove hue kyunki unki adoption kam thi; aaj GraalVM Native Image preferred solution hai.

💡 **Yaad rakhna:** Interview me kabhi mat bolna **"Java 17 ne JIT Compiler remove kar diya."** Ye **galat** answer hoga. Remove sirf **experimental AOT compiler aur experimental Graal JIT integration** hua tha; normal **HotSpot JIT Compiler** aaj bhi Java ka core part hai.
