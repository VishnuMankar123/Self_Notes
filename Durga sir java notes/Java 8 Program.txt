# MODULE 1 : Java 8 Stream Basics

## Part 1 : Stream Kya Hai?

### Definition (Interview)

**Stream is a sequence of elements that supports functional operations to process data without modifying the original collection.**

### Simple Hindi-English

Socho tumhare paas ek List hai.

```java
List<String> names =
Arrays.asList("Vishnu","Rahul","Amit");
```

Ab tum

* filter karna chahte ho
* sort karna chahte ho
* uppercase karna chahte ho
* count karna chahte ho

Ye sab kaam Stream karta hai.

So,

```text
Collection
      |
      v
  Stream
      |
      v
Processing
      |
      v
Result
```

# Important Interview Point

## Stream Original Collection Change Nahi Karta

Example

```java
List<Integer> list =
Arrays.asList(5,2,1);

list.stream()
.sorted()
.forEach(System.out::println);

System.out.println(list);
```

Output

```
1
2
5

[5,2,1]
```

Original list same hai.

**Interview Question**

**Q : Does Stream modify original Collection?**

**Answer**

**No. Stream never modifies the original collection. It only processes data and returns a new result.**

# Lazy Evaluation

Ye Java 8 ka favourite interview topic hai.

Example

```java
list.stream()
.filter(i->{

System.out.println(i);

return i>2;

});
```

Output?

```
Nothing
```

Kyuki execute hi nahi hua.

Ab

```java
list.stream()
.filter(i->{

System.out.println(i);

return i>2;

})
.collect(Collectors.toList());
```

Output

```
1
2
3
4
5
```

Ab execute hua.

---

# Why?

Intermediate operations lazy hote hain.

Execution tab hota hai jab terminal operation aata hai.

# Interview Question

**Q : Why are Streams Lazy?**

Answer

Lazy evaluation improves performance because processing starts only when a terminal operation is invoked.

# Interview Question

Difference between External and Internal Iteration?

| External Iteration      | Internal Iteration        |
| ----------------------- | ------------------------- |
| for loop                | Stream                    |
| Developer controls loop | Stream controls iteration |
| More code               | Less code                 |
| Sequential              | Sequential/Parallel       |

---

# Stream vs Collection

| Collection              | Stream                  |
| ----------------------- | ----------------------- |
| Stores Data             | Processes Data          |
| Mutable                 | Doesn't modify source   |
| Can iterate many times  | One-time use            |
| Uses External Iteration | Uses Internal Iteration |

---

Ye interview me bahut poochte hain.

```java
stream.forEach(System.out::println);

stream.forEach(System.out::println);
```

Output

```

```

Reason

```
Stream already consumed.
```

# Interview Question

Answer

# 1. Filter Kya Hai?

## Definition

`filter()` Stream ka **Intermediate Operation** hai.

Ye **Predicate Functional Interface** use karta hai.

Har element par condition check karta hai.

* Condition True → Element aage jayega.
* Condition False → Element remove ho jayega.

---

## Syntax

```java
stream()
.filter(condition)
.collect(Collectors.toList());
```

# 1. map() Kya Hai?

`map()` ek **Intermediate Operation** hai.

Ye **Function Functional Interface** use karta hai.

Ye har element ko **ek naye element me convert (transform)** karta hai.

# map() vs filter()

| filter()               | map()                |
| ---------------------- | -------------------- |
| Removes data           | Changes data         |
| Uses Predicate         | Uses Function        |
| Returns True/False     | Returns New Value    |
| Same data type usually | Data type can change |



# ⭐ Interview Master Tip

Real interviews me **`filter()` + `map()` + `max()`** ka combination bahut common hai.

Example:

```java
Employee highestPaidITEmployee = employees.stream()
        .filter(emp -> "IT".equals(emp.getDepartment())) // Only IT employees
        .max(Comparator.comparing(Employee::getSalary))  // Highest salary
        .orElse(null);

System.out.println(highestPaidITEmployee);
```

**Flow:**

```text
Employee List
      ↓
filter() → IT Department
      ↓
max()    → Highest Salary
      ↓
Optional
      ↓
orElse()/get()
      ↓
Result
```

Ye pattern Spring Boot aur Java Backend interviews me bahut frequently poocha jata hai.
