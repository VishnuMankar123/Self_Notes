# Time Complexity & Space Complexity Interview Notes

---

# 1. Time Complexity

## Time Complexity kya hai?

### Interview me aise bolo:

> **Time Complexity batati hai ki input size badhne par algorithm kitna work karega ya kitne operations perform karega. Ye actual seconds nahi batati, sirf growth batati hai.**

---

## Easy Example

```java
for(int i=0;i<n;i++){
    System.out.println(i);
}
```

Agar

```
n = 5
```

Loop

```
5 times
```

Agar

```
n = 100
```

Loop

```
100 times
```

Isliye

```
Time Complexity = O(n)
```

---

# 2. Space Complexity

## Space Complexity kya hai?

### Interview me aise bolo:

> **Space Complexity batati hai ki algorithm ko execute karne ke liye extra memory kitni chahiye. Hum input ki memory nahi, sirf extra memory count karte hain.**

---

## Example

```java
int a = 10;
int b = 20;
```

Sirf

```
2 variables
```

```
Space Complexity = O(1)
```

## Example

Memory

```
10 integers
```

Agar

```

```

# Factorial Example

## Using Loop

```java
public static long factorial(int n){

    long fact=1;

    for(int i=1;i<=n;i++){

        fact*=i;

    }

    return fact;

}
```

### Time Complexity

Loop

↓

```
n times
```

```
O(n)
```

### Space Complexity

Variables

```
fact

i
```

Bas.

```
O(1)
```

---

## Factorial using Recursion

```java
public static long factorial(int n){

    if(n==1)
        return 1;

    return n*factorial(n-1);

}
```

Call Stack

```
factorial(5)

↓

factorial(4)

↓

factorial(3)

↓

factorial(2)

↓

factorial(1)
```

### Time Complexity

```
O(n)
```

### Space Complexity

Har function call memory use karta hai.

```
5 Calls

↓

5 Stack Frames
```

```
O(n)
```

## 💡 Mujhe lagta hai tumhari confusion ek hi jagah hai:

**Tum "print karna" aur "memory me store karna" dono ko same samajh rahe ho.**

Ye dono alag cheezein hain.

* **Print** → Memory nahi badhti → `O(1)` Space
* **Store (Array/List/StringBuilder)** → Memory badhti hai → `O(n)` Space

Agar ye concept clear ho gaya, to tum 90% Space Complexity khud nikal loge.
