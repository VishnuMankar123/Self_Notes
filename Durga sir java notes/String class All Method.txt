# Complete Methods of java.util.Objects

## 1. equals()

### Signature

```java

```

### Input

```text
Object a
Object b
```

### Return

```text
boolean
```

### Example

```java
System.out.println(
    Objects.equals("Java","Java")
);
```

Output

```

```

### Internal Logic

```java
if(a==b)
   return true;

if(a==null || b==null)
   return false;

return a.equals(b);
```

# Java 8 Stream Examples

### Count Digits

```java
String str = "abc123";

long count = str.chars()
                .filter(ch -> Character.isDigit(ch))
                .count();

System.out.println(count);
```

Output

```text
3
```

---

### Count Alphabets

```java
String str = "abc123";

long count = str.chars()
                .filter(ch -> Character.isLetter(ch))
                .count();

System.out.println(count);
```

Output

```text
3
```

---

### Convert Lowercase to Uppercase

```java
String result = "java"
        .chars()
        .map(Character::toUpperCase)
        .mapToObj(ch -> String.valueOf((char) ch))
        .collect(Collectors.joining());

System.out.println(result);
```

Output

```text
JAVA
```
