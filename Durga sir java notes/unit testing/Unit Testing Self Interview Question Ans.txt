# JUnit Interview Questions & Answers (Part 1)

# Q1. What is JUnit?

### 👨‍💼 Interviewer

What is JUnit?

### 👨‍💻 You

JUnit ek **Java Testing Framework** hai jo **Unit Testing** ke liye use hota hai.

Iska main purpose individual methods ya units ko test karna hota hai.

Isse hum verify karte hain ki hamara business logic expected result de raha hai ya nahi.

Normally Spring Boot projects me JUnit 5 use hota hai.

### ⭐ One Line Answer

> **JUnit is a Java Testing Framework used to perform Unit Testing.**

### 💡 Real Project

Main Service Layer ke methods jaise `save()`, `update()`, `delete()` aur `getById()` ko JUnit se test karta hoon.

---

# Q2. What is Unit Testing?

### 👨‍💼 Interviewer

What is Unit Testing?

### 👨‍💻 You

Unit Testing ka matlab application ki **smallest testable unit** ko independently test karna.

Generally ek method ya function ko test kiya jata hai.

Isme hum sirf business logic test karte hain.

Database, API ya Kafka ko include nahi karte.

### ⭐ One Line Answer

> Unit Testing means testing one method or one unit independently.

### ⭐ Memory Trick

```text
One Method

↓

One Test

↓

Unit Testing
```

---

# Q3. Why do we use JUnit?

### 👨‍💼 Interviewer

Why do we use JUnit?

### 👨‍💻 You

JUnit use karte hain

* Business Logic verify karne ke liye
* Bugs jaldi detect karne ke liye
* Code Quality improve karne ke liye
* Refactoring ke baad ensure karne ke liye ki existing functionality break na ho.

### ⭐ One Line Answer

> JUnit is used to verify business logic automatically.

---

# Q4. What is the difference between Testing and Unit Testing?

### 👨‍💼 Interviewer

Difference between Testing and Unit Testing?

### 👨‍💻 You

Testing ka matlab complete application ko verify karna.

Unit Testing ka matlab sirf ek method ya unit ko independently verify karna.

### Table

| Testing              | Unit Testing      |
| -------------------- | ----------------- |
| Complete Application | Single Method     |
| Manual ya Automation | Mostly Automation |
| Multiple Modules     | Single Unit       |

---

### 👨‍💼 Interviewer

Why should developers write Unit Test Cases?

* Bugs early mil jate hain.

* Refactoring easy ho jati hai.
* Code reliable ban jata hai.
* Deployment se pehle confidence milta hai.

### ⭐ Interview Tip

Production bug fix karna expensive hota hai.

Unit Test us bug ko development time par hi pakad leta hai.

# Q1. What is @Test Annotation?

### 👨‍💼 Interviewer

What is @Test annotation?

### 👨‍💻 You

`@Test` JUnit ko batata hai ki ye method ek **Test Case** hai.

JUnit sirf unhi methods ko execute karta hai jinke upar `@Test` laga hota hai.

### ⭐ One Line Answer

> **@Test is used to mark a method as a test case.**

---

# Q2. What happens if we don't use @Test?

### 👨‍💼 Interviewer

Agar @Test remove kar dein to kya hoga?

### 👨‍💻 You

Method normal Java method ban jayega.

JUnit us method ko execute nahi karega.

### ⭐ Interview Tip

Ye bahut common follow-up question hai.

---

# Q3. What is @BeforeEach?

### 👨‍💼 Interviewer

What is @BeforeEach?

### 👨‍💻 You

`@BeforeEach` har Test Case execute hone se pehle run hota hai.

Generally object creation, mock initialization aur common setup ke liye use hota hai.

### Example

```java
@BeforeEach
void setup(){

    service=new UserService();

}
```

---

# Q4. Why do we use @BeforeEach?

### 👨‍💻 You

Code duplicate na ho.

Agar 20 Test Cases hain aur har baar object banana hai,

to ek hi jagah `@BeforeEach` me likh dete hain.

### ⭐ One Line

> Common setup before every test.

---

# Q5. What is @AfterEach?

### 👨‍💼 Interviewer

What is @AfterEach?

### 👨‍💻 You

Har Test Case complete hone ke baad execute hota hai.

Cleanup ke liye use hota hai.

Example

* Clear Cache
* Close Streams
* Reset Variables

---

# Q6. What is @BeforeAll?

### 👨‍💼 Interviewer

What is @BeforeAll?

### 👨‍💻 You

`@BeforeAll` sabhi Test Cases se pehle sirf **ek baar** execute hota hai.

Heavy initialization ke liye use karte hain.

Example

* Database Connection
* Configuration Loading
* Expensive Resource Creation

---

# Q7. Why must @BeforeAll method be static?

### 👨‍💼 Interviewer

Why static?

### 👨‍💻 You

Kyuki ye object create hone se pehle execute hota hai.

Isliye JUnit object create kiye bina method call karta hai.

### ⭐ One Line

> It runs at class level before object creation.

---

# Q8. What is @AfterAll?

### 👨‍💼 Interviewer

What is @AfterAll?

### 👨‍💻 You

Sabhi Test Cases complete hone ke baad sirf ek baar execute hota hai.

Cleanup ke liye use hota hai.

Example

* Close Database Connection
* Release Resources

---

# Q9. What is the execution order of JUnit 5 annotations?

### 👨‍💼 Interviewer

Execution order batao.

### 👨‍💻 You

```text
@BeforeAll

↓

@BeforeEach

↓

@Test

↓

@AfterEach

↓

@BeforeEach

↓

@Test

↓

@AfterEach

↓

@AfterAll
```

### ⭐ Memory Trick

> **All → Each → Test → Each → All**

# Q1. What is Mockito?

> **Mockito is a Java Mocking Framework used to create fake objects for Unit Testing.**

# Q2. Why do we need Mockito?

### 👨‍💼 Interviewer

JUnit to hai hi, fir Mockito ki kya zarurat hai?

### 👨‍💻 You

JUnit sirf Test Cases run karta hai.

Lekin agar Service ke andar Repository ya External API call ho rahi ho,

to JUnit us dependency ko fake nahi bana sakta.

Mockito fake dependencies create karta hai.

# Q1. What is @Spy?

### 👨‍💼 Interviewer

What is @Spy?

### 👨‍💻 You

`@Spy` real object create karta hai, lekin agar zarurat ho to uske kuch methods ko mock bhi kar sakte hain.

Matlab object ka actual behavior bhi use kar sakte hain aur specific methods ka mocked behavior bhi define kar sakte hain.

### Example

```java
@Spy
private ArrayList<String> list = new ArrayList<>();
```

### ⭐ One Line Answer

> **@Spy creates a real object with partial mocking capability.**

---

# Q2. Difference between @Mock and @Spy?

### 👨‍💼 Interviewer

Difference between Mock and Spy?

### 👨‍💻 You

| @Mock              | @Spy                            |
| ------------------ | ------------------------------- |
| Fake Object        | Real Object                     |
| All methods mocked | Real methods execute by default |
| No real logic      | Partial real logic              |

### ⭐ Memory Trick

```text
@Mock

↓

Fake Object

@No Real Logic

----------------

@Spy

↓

Real Object

↓

Partial Mock
```

---

# Q3. When do you use @Spy?

### 👨‍💻 You

Jab object ka mostly real behavior chahiye ho,

lekin ek ya do methods ko override karna ho.

Example

Utility Classes

Legacy Code

Complex Business Classes

# Q4. What is @MockBean?

### 👨‍💼 Interviewer

What is @MockBean?

### 👨‍💻 You

`@MockBean` Spring Boot annotation hai.

Ye Spring Application Context ke andar real bean ko mock bean se replace kar deta hai.

Mostly Integration Testing me use hota hai.

### Example

```java
@MockBean
private UserRepository repository;
```

| Mockito                        | Spring Boot                   |
| Unit Test                      | Integration Test              |
| Spring Context start nahi hota | Spring Context start hota hai |

### ⭐ Interview Tip

Ye question almost har interview me poocha jata hai.

# Q7. What is ArgumentCaptor?

### 👨‍💼 Interviewer

What is ArgumentCaptor?

### 👨‍💻 You

ArgumentCaptor method ko pass hone wale arguments ko capture karta hai.

Jab verify karna ho ki actual me kaunsa object pass hua,

tab use karte hain.

---

### Example

```java
ArgumentCaptor<User> captor =
ArgumentCaptor.forClass(User.class);

verify(repository).save(captor.capture());

assertEquals("Vishnu",
captor.getValue().getName());
```

---

# Q8. Why do we use ArgumentCaptor?

### 👨‍💻 You

Kabhi-kabhi object directly compare nahi kar sakte.

Us case me argument capture karke uski values verify karte hain.

---

# Q9. What is InOrder?

### 👨‍💼 Interviewer

What is InOrder?

### 👨‍💻 You

`InOrder` verify karta hai ki methods kis sequence me call hue.

---

### Example

```java
InOrder order = inOrder(repository);

order.verify(repository).save(user);

order.verify(repository).deleteById(1L);
```

# Q10. Why use InOrder?

### 👨‍💻 You

Jab execution sequence important ho.

Example

```text
Save

↓

Update

↓

Delete
```

# Q11. What is BDDMockito?

### 👨‍💼 Interviewer

What is BDDMockito?

### 👨‍💻 You

BDDMockito Mockito ka Behavior Driven version hai.

Ye code ko zyada readable banata hai.

---

### Example

Instead of

```java
when(service.save(user))
.thenReturn(user);
```

Use

```java
given(service.save(user))
.willReturn(user);
```

---

# Q12. Difference between Mockito and BDDMockito?

| Mockito      | BDDMockito   |
| ------------ | ------------ |
| when()       | given()      |
| thenReturn() | willReturn() |

---

# Q13. What is doAnswer()?

### 👨‍💼 Interviewer

What is doAnswer()?

### 👨‍💻 You

Dynamic response return karna ho,

ya method ke arguments ke basis par logic execute karna ho,

to `doAnswer()` use karte hain.

---

### Example

```java
doAnswer(invocation -> {

    User user = invocation.getArgument(0);

    return user;

}).when(repository).save(any());
```

---

# Q14. Difference between doAnswer() and thenReturn()?

| thenReturn()   | doAnswer()       |
| -------------- | ---------------- |
| Fixed Response | Dynamic Response |
