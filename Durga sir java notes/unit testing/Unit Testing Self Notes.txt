# ⭐ Interview Quick Revision

### Q1. What is Testing?

Testing means verifying whether the written code behaves as expected.

---

### Q2. What is Unit Testing?

Testing one method/function independently.

---

### Q3. What is Integration Testing?

Testing multiple modules/components together.

---

### Q4. Why do we use JUnit?

To write, execute, and verify Unit Test cases automatically.

---

### Q5. Why do companies perform Unit Testing?

* Early bug detection
* Reduce cost
* Reduce development time
* Improve software quality
* Safe refactoring

---

### Q6. Which JUnit versions are important?

* **JUnit 4** (Legacy Projects)
* **JUnit 5** (Modern Projects)

---

### Q7. What is Mockito?

Mockito is a mocking framework that creates fake objects to test classes without using real dependencies like databases or external APIs.

| -------------- | --------------------- | ------- | ---------------- |

# 15. @Mock vs @MockBean

Bahut Important

Interview Favorite.

## @Mock

Mockito Annotation

Unit Testing

Spring Context

Start nahi hota.

---

## @MockBean

Spring Boot Annotation

Spring Context ke andar

Real Bean ko

Mock Bean se replace karta hai.

---

Comparison

| @Mock               | @MockBean                     |
| ------------------- | ----------------------------- |
| Mockito             | Spring Boot                   |
| Unit Test           | Integration Test              |
| Fast                | Slow                          |
| Spring Context nahi | Spring Context start hota hai |

---

# Interview Question

Difference between @Mock and @MockBean?

Answer

@Mock creates a Mockito mock.

@MockBean replaces a Spring Bean with a mock inside the Spring Application Context.

Repository Layer.
