# 1. String Template Kya Hai?

### 👨‍🏫 Teacher:

Java 21 me sabse interesting feature kaunsa hai?

### 👨‍🎓 Student:

Sir, **String Templates**.

Is feature ki help se hum string ke andar directly variables aur expressions likh sakte hain.

Pehle hume **concatenation (+)** use karna padta tha.

Ab Java khud runtime par value replace kar deta hai.

---

## Easy Definition

> **String Template** ek naya feature hai jisme hum string ke andar direct variable ya expression likh sakte hain.

---

# Real Life Example

Suppose aap WhatsApp message bana rahe ho.

Pehle

```java
String msg = "Hello " + name;
```

Ab

```java
String msg = STR."Hello \{name}";
```

Kitna clean lag raha hai.

---

# 2. Java 21 se Pehle Kaise Karte The?

### 👨‍🏫 Teacher:

Java 20 ya Java 17 me variable string ke andar kaise likhte the?

### 👨‍🎓 Student:

Concatenation use karte the.

Example

```java
String name = "Vishnu";

System.out.println("Hello " + name);
```

Output

```
Hello Vishnu
```

---

## Agar Multiple Variables Ho?

```java
String name = "Vishnu";
int age = 29;

System.out.println("Name : " + name + " Age : " + age);
```

Output

```
Name : Vishnu Age : 29
```

Dekho kitne saare **+** lag gaye.

Code readable nahi lag raha.

---

# Problem with Concatenation

* Code lamba ho jata hai.
* Readability kam ho jati hai.
* Multiple variables me confusion hota hai.
* HTML ya SQL banana difficult hota hai.

Isi problem ko solve karne ke liye Java 21 me **String Templates** introduce hue.

# 3. String Template Ka Idea

### 👨‍🏫 Teacher:

String Template ka basic idea kya hai?

### 👨‍🎓 Student:

Hum string ke andar hi variable likhenge.

Java runtime par automatically uski value replace kar dega.

---

## Example

```java

```

Instead of

```java
"Hello " + name
```

Use

```java
STR."Hello \{name}"
```

Output

```
Hello Rahul
```

---

# 4. STR Kya Hai?

### 👨‍🏫 Teacher:

Ye **Template Processor** hai.

Ye string ko process karta hai.

Aur

```
\{ }
```

ke andar jo expression hota hai uski value calculate karke string me replace karta hai.

---

# 18. SQL Injection Danger

### 👨‍🏫 Teacher:

Video me sir ne bola String Template dangerous bhi ho sakta hai.

Kaise?

### 👨‍🎓 Student:

Agar user ki input directly SQL query me daal di to attacker malicious input bhej sakta hai.

Example

```java
String username=input;
```

```java
String sql=

STR."""

SELECT *

FROM USER

WHERE NAME=\{username}

""";
```

Agar attacker bheje

```
' OR 1=1 --
```

Final Query

```sql
SELECT *

FROM USER

WHERE NAME=' OR 1=1 --
```

Ye poori table return kar sakti hai.

Isko **SQL Injection** bolte hain.

---

# Real Life Rule

Kabhi bhi

❌ User input directly SQL me mat daalo.

Always

✅ PreparedStatement use karo.

# 🎯 Interview Questions

---

## Q1. String Template kya hai?

**Answer:**

String Template Java 21 ka preview feature hai jisme hum string ke andar directly variables ya expressions likh sakte hain. Java runtime par unki value replace kar deta hai.

---

## Q2. String Template kyu introduce hua?

**Answer:**

Concatenation (`+`) ko kam karne, code ko readable banane aur HTML/JSON/SQL jaise text ko easily create karne ke liye.

---

## Q3. STR kya hai?

**Answer:**

**STR** ek **Template Processor** hai jo string template ko process karta hai aur `\{}` ke andar ke expressions ko evaluate karke final string banata hai.

---

## Q4. Kya String Template me sirf variable hi use kar sakte hain?

**Answer:**

Nahi. Variable ke saath expressions (`a+b`), method calls (`name.toUpperCase()`) aur function calls bhi use kar sakte hain.

---

## Q5. String Template kab value replace karta hai?

**Answer:**

Runtime par.

---

## Q6. Ye feature permanent hai?

**Answer:**

Nahi. Ye Java 21 ka **Preview Feature** hai.

---

## Q7. Preview feature compile karne ke liye kya command use karte hain?

**Answer:**

```bash
javac --enable-preview --release 21 Main.java
```

Run karne ke liye:

```bash
java --enable-preview Main
```

---

## Q8. String Template ka sabse bada benefit kya hai?

**Answer:**

Readable code aur kam concatenation.

---

## Q9. String Template use karte waqt security concern kya hai?

**Answer:**

Agar user input ko directly SQL query me use karein, to **SQL Injection** ka risk hota hai. Isliye **PreparedStatement** use karna chahiye.

---

## Q10. String Template kin scenarios me useful hai?

**Answer:**

* HTML generate karna
* JSON banana
* SQL query banana (safe approach ke saath)
* Dynamic messages banana

---

# 📌 Part 2 Summary

* **String Templates** Java 21 ka **Preview Feature** hai.
* Isme `STR` template processor aur `\{}` syntax se variables aur expressions ko string ke andar directly use kar sakte hain.
* Ye concatenation (`+`) ki need ko kam karta hai aur code ko zyada readable banata hai.
* HTML, JSON aur dynamic messages banana bahut easy ho jata hai.
* Preview feature hone ki wajah se `--enable-preview` ke saath compile aur run karna padta hai.
* SQL queries me direct user input use karne se **SQL Injection** ka risk hota hai, isliye **PreparedStatement** prefer karna chahiye.
